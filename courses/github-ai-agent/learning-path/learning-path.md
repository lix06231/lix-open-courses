# 学习路径

## 推荐方式：一次读完

预计 60-90 分钟。

1. 第 1-4 章：建立 GitHub、Git 和 Repo 的基础地图；
2. 第 5-8 章：理解 Agent 使用 Git 时的修改、提交与同步流程；
3. 第 9-12 章：建立项目说明、安全边界和可直接复用的指令模板；
4. 阅读最后的十句话总结，回顾自己仍然容易混淆的概念。

## 轻量方式：分三次学习

### 第一次：先消除陌生感

阅读第 1-4 章。目标是看到 Repo、Clone、Fork 时知道它们分别在说什么。

### 第二次：看懂 Agent 的操作

阅读第 5-8 章。目标是理解 Status、Diff、Commit、Branch、PR、Push 和 Pull，并知道哪些动作应该先确认。

### 第三次：形成自己的安全工作流

阅读第 9-12 章。把适合自己的提示词保存下来，并尝试用一个不重要的小项目走完“检查 - 修改 - 验证 - 提交 - 上传”的过程。

## 学完后的第一次实践

找一个你自己的普通文件夹，让 Agent：

1. 只检查 Git 是否安装，不做修改；
2. 解释怎样把文件夹初始化成 Git 仓库；
3. 初始化后展示 Status；
4. 创建一个很小的 README；
5. 展示 Diff，等你确认；
6. 再创建第一次 Commit。

这个练习不需要马上上传 GitHub，重点是先看懂本地 Git 如何记录 Agent 的工作。
