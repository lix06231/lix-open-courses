# 课程信息

## 基本信息

- 课程名称：普通人也能看懂的 GitHub｜AI Agent 小白课
- 当前版本：v0.2
- 更新日期：2026-08-15
- 课程规模：12 章
- 预计学习时间：60-90 分钟
- 前置要求：不要求编程基础
- 主要载体：完整 HTML、试学 HTML、PDF

## 适合谁

- 已经开始使用 AI Agent，但不理解 GitHub 基础概念的人；
- 想安装 GitHub 上的 Skill、MCP 或开源工具，却担心看不懂操作的人；
- 想让 Agent 长期修改项目，并保留版本和退路的人；
- 想把自己的 HTML、课程或其他数字成果发布到 GitHub 的人。

## 学完以后

你应该能够区分 Git、GitHub 和 Repository，理解 Download、Clone、Fork、Commit、Branch、Pull Request、Push 与 Pull 的作用，并知道怎样要求 Agent 在修改、提交、上传和处理密钥时遵守基本安全边界。

## 内容边界

这不是面向程序员的 Git 命令手册，也不会覆盖复杂分支策略、底层对象模型或团队级 DevOps。课程重点是让普通人听懂 Agent 准备做什么，并能在关键节点进行确认和验收。

## 主要参考

课程主要参考 GitHub 官方文档、Codex 项目说明文档与 Claude Code 项目记忆文档。详细链接列在完整教材末尾。
